# Project Rules for Sandane Homes

## Hotel Naming Conventions
- **CoCo House**: Always use **"CoCo House"** ONLY. NEVER append "by Sandane Homes" or "/ Sandane Homes".
- **Other Hotels (Amaaltash, The Glam, Saffron Inn, Amara Inn, Pine Tales, Residences)**: Use **"by Sandane Homes"** (e.g. "Amaaltash by Sandane Homes", "The Glam by Sandane Homes"). Do NOT use slashes like "/ Sandane Homes".
