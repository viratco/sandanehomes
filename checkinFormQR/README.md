# Sandane Homes — Guest Registration

## Overview
A mobile-first hotel guest registration form for Sandane Homes.
Submits directly to Google Sheets via Google Apps Script. No backend server needed.

## Quick Start

```bash
npm install
npm run dev
```

## Setup
See [SETUP.md](./SETUP.md) for full configuration instructions.

## Tech Stack
- **Frontend:** Vite + React
- **Backend:** Google Apps Script (no server)
- **Database:** Google Sheets
- **Document Storage:** Google Drive (private)
- **Hosting:** Vercel
